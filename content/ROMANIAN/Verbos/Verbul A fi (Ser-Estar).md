# Verbul "A fi"
___
- Eu ==sunt==  (Eu îs/Eu mi-s  )
- Tu ==Ești==  
- El/Ea ==este==  (El/Ea îi)

- Noi ==suntem==  
- Voi ==sunteți==  
- Ei/Ele ==sunt==  (Ei/Ele îs  )


>[!Example] **Preguntas**
>- Cine ==ești tu==? - Quien eres tu?  
>- Ce ==ești tu== - Que? eres tu?  
>- De unde ==ești tu==? - De donde eres tu?  
>- ==Tu== de unde ==ești==? - De donde eres tu?  
>- Unde ==suntem noi==? - Donde estamos?

## Abreviación ser y estar
___
Ea este - Ea e  
El Este - El e  
  
Ea nu este - Ea nu-i  
El nu este - El nu-i  

  >[!Example] **Ejemplo**
>-Adrian e contabil?  
>+Da, el e contabil  
>+Nu, el nu-i contabil  
>+El e inginer  

>[!Example] **Ejemplo**
>-Maria e profesoară?  
>+Da, ea e profesoară  
>+Nu, ea nu-i profesoară  
>+Ea e medic  

>[!Example] **Ejemplo**
>-Andrea e achitectă?  
>-Da, ea e arhitectă  
>+Nu, ea nu-i architectă  
>+Ea e secretară  

>[!Example] **Ejemplo**
>-Radu este zidar?  
>+Da, el e zidar  
>+Nu, el nu-i zidar  
>+El e avocat  
  

# Pasado - Pretérito perfecto compuesto
___
>[!Info] Trecutul - Perfectul compus
>Sirve para expresar las dos formas del pasado, tanto el más lejano como el más reciente

Auxiliar A avea + Participio Verbo.

>[!Info] Vb A avea
>Cuando el vb A avea es predicativo es sinónimo de tener

| Preicativo |                    | Auxiliar       |                    |
| ---------- | ------------------ | -------------- | ------------------ |
| Eu am      | Yo tengo           | Eu am...       | Yo he...           |
| Tu ai      | Tu tienes          | Tu ai...       | Tú has...          |
| El/Ea are  | Él/Ella tiene      | El/Ea ==a==... | Él/Ella ha...      |
| Noi avem   | Nosotros tenemos   | Noi ==am==...  | Nosotros hemos...  |
| Vou aveți  | Vosotros tenéis    | Vou ==ați==... | Vosotros habéis... |
| Ei/Ele au  | Ellos/Ellas tienen | Ei/Ele au...   | Ellos/Ellas han... |

>[!Info] Reconocer participio
>El participio de ser estar acaba en -T
>- A fi - Fost (Ser - Sido, Estar - Estado)

| Eu am fost       | Yo he sido/estado           |
| ---------------- | --------------------------- |
| Tu ai fost       | Tú has sido/estado          |
| El/Ea ==a== fost | Él/Ella ha sido/estado      |
| Noi ==am== fost  | Nosotros hemos sido/estado  |
| Vou ==ats== fost | Vosotros habéis sido/estado |
| Ei/Ele au fost   | Ellos/Ellas han sido/estado |

- (Ser) Eu am fost mecanic, dar acum sunt inginer. - Yo antes era mecanico, pero ahora soy ingeniero.
- (Estar) Ei au fost la Londra acum un an. - Ellos fueron a londres hace un año.
- (Ir) Noi am fost la concert. - Nostros fuemos al concierto.


# Futuro - Viitorul
___
Mientras que en castellano las terminaciones del futuro se añaden al final del verbo a conjugar, en rumano se forma:

Auxiliar A vrea + Infinitivo Verbo (A fi).

| Preicativo |                     | Auxiliar   |                   |
| ---------- | ------------------- | ---------- | ----------------- |
| Eu vreau   | Yo quiero           | Eu voi     | Yo ...é           |
| Tu vrei    | Tu quieres          | Tu vei     | Tú ...ás          |
| El/Ea vrea | Él/Ella quiere      | El/Ea va   | Él/Ella ...á      |
| Noi vrem   | Nosotros queremos   | Noi vom    | Nosotros ...émos  |
| Vou vreți  | Vosotros queréis    | Vou veți   | Vosotros ...éis   |
| Ei/Ele vor | Ellos/Ellas quieren | Ei/Ele vor | Ellos/Ellas ...án |

| Eu voi fi     | Yo seré/estaré             |
| ------------- | -------------------------- |
| Tu vei fi     | Tú serás/estarás           |
| El/Ea va fi   | Él/Ella será/estará        |
| Noi vom fi    | Nosotros serémos/estarémos |
| Vou veți fi   | Vosotros seréis/estaréis   |
| Ei/Ele vor fi | Ellos/Ellas serán/estarán  |
- (Ser) Eu voi fi inginer. - Yo seré ingeniero.
- (Estar) Ei voi fi la Londra anul viitor. - Ellos iran a londres el año que viene.

___
1. Eu ... medic, dar acum ... pensionar.
2. Anul viitor el ... la Chicago.
3. Noi ... la un camping în Italia în acest moment.
4. Tu ... la curs, dar ea  ... la coafor acum.
5. Voi ... la Zoo anul trecut.
