# Terminaciones equivalentes
---
-dad/-tate
-mento/-ment
-dor/-tor
-ción/ție
-ble/-bil

### -ble/-bil
- amable - amabil
- estable - stabil
- inefable - inefabil
- ACEPTABLE = ACCEPTABIL
- DISPONIBLE = DISPONIBIL
- FRIABLE = FRIABIL
- ILEGIBLE = ILIGIBIL
- IMPALPABLE = IMPALPABIL
- INCONFUNDIBLE = INCONFUNDABIL
- (IN)FLEXIBLE = (IN)FLEXIBIL
- LOCALIZABLE = LOCALIZABIL
- VULNERABLE = VULNERABIL

### -ción/ție
- atención - atenție
- creación - creație
- solución - soluție

### -dad/-tate
- fraternidad - fraternitate
- libertad - libertate
- igualidad - egalitate
- universidad - universitate
- soledad - singurătate

### -dor/-tor
- trabajador - muncitor
- trabajadora - muncitoare
- operador - operator
- operadora - operatoare



NO EQUIVALENTES:
- CORROMPIBLE = CORUPTIBIL
- DOBLE = DUBLU
- INFLABLE = GONFLABIL
- INTOCABLE = DE NEATINS
- MEDIBLE = MĂSURABIL
- PREVENIBLE = PREVENTIV
- REBATIBLE = DISCUTABIL
