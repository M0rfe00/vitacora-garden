Prefijos utiles  
Letras o grupos de letras que se añaden delante de la raíz de una palabra para obteneter una nueva con un sentido diferente. (En rumano hay unos 100 aprox)  
  
#Negativos  
Ne-   
Atent -> neatent (no atento/Despistado)  
Firesc -> nefiresc (anormal)  
Locuit -> nolocuit (inhabilitado)  
  
In-/Im-  
Corect -> incorect (incorrecto)  
Succes -> insucces (Fracaso)  
  
Pur -> Impur (impuro)  
Permeabil -> impermeabil (Impermeable)  
  
#Iterativos  
Re-  
A citi -> A reciti (releer)  
A intra -> A reintra (Reentrar)  
A vinde -> A revinde (Revender)  
A organiza -> A reorganiza (Reorganizar)  
  
Răz   
A se gândi -> A se răzgândi (Repensar)  
  
  
#Oposición  
În/Îm- vs- des-/dez-  
A se înclța -> A se descălța (descalzarse)  
Încalțat -> descălțat (descalzo)  
  
A închide -> A deschide (cerrar)  
Închis -> Deschis (Abierto)  
  
A Încuraja -> A descuraja (Desanimar)  
Încurajat -> Descurajat (Desanimado)  
  
A împacheta -> a despacheta (desempaquetar)  
A Împărți -> A despărți (Dividir/Separar)  
  
A se îmbrăca -> A se dezbrăca (Desvestirse)  
Îmbrăcat -> dezbrăcat (Desvestido/Desnudo)  
  
  
(Verbo vs- dez-/dez- + verbo)  
A lipi -> a dezlipi (despegar)  
Lipit -> dezlipit (despegado)  
  
  
(Vb vs. de- + vb)  
A congela -> A decongela (descongelar)  
Congelat -> decongelat (descongelado)  
  
A conecta - a desconecta (desconectar)  
Conectat - Desconectat (Desconectado)  
  
A săra -> A desăra (Desalar)  
Sărat -> Desărat (Desalado)  
  
A acopere -> A descoperi (Descubrir)  
Acoperit -> Descoperit (Descubierto)  
  
A face - A desface (Deshacer)  
Făcut -> Desfăcut (Deshecho)
